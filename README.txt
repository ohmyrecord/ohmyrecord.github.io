          → 06 작동 구조(입력 → AI 판단 → 물리적 반응) → 07 크기·소재 → 08 다시 명동으로
  - FOLD MARK 직접 해 보기: 끌어서 360° 회전(처음엔 살짝 흔들려 돌릴 수 있음을 알려 줌) · '여기를 툭' 안내 · 앞 빛 띠 신호 4가지(대기 / 고르는 중 / 출력 완료 / 빈자리 없음) 미리 보기
      · 주먹 홈을 누르거나 '툭 치기'(Space) → 빛 선 깜박(AI가 고르는 중) → 윗면 틈에서 약도 스티커가 나옴
      · 스티커 언어 한국어 / English / 日本語, 누를 때마다 다음 손님의 번호 · 도착 시각이 바뀜
      · 스티커는 상민님 스티커 배치(Tray print)를 따라 코드로 그립니다 (QR 은 모양만)
  - STREET FOLD 부위 탐색: 점이나 목록을 누르면 그 부분으로 카메라가 다가감
      번호등(예약/비어 있음) · 디스플레이(상태 3가지) · 대는 곳(대면 판이 내려옴) · 판(내려오며 가까이)
      · 쓰레기통 모듈(앞으로 기울어 나옴) · 카드 태그(대면 쓰레기통이 기울어 나옴)
      ※ 모델에 쓰레기통 몸통이 따로 없어서, 앞판 크기에 맞춰 몸통을 코드로 만들어 붙였습니다.
  - 실사 시나리오 이미지 · 영상을 넣는 곳: index.html 의 #ppStoryMedia 안에 <img> 6장을 순서대로 넣으면
    이야기 6장면에 맞춰 바뀝니다. (영상이면 <video muted playsinline loop autoplay>)
  - 렌더 이미지(360° 72장 등)를 받으면 3D 대신 / 옆에 실사 회전으로 바꿀 예정입니다.
